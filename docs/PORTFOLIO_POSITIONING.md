# Portfolio positioning

This is an independent portfolio project built on publicly available Yorkshire Water data. It is not an official Yorkshire Water system and is not affiliated with Yorkshire Water.

The project is designed to demonstrate senior data-science work in a regulated utility setting: reproducible source handling, decision-oriented analysis, time-aware model validation, baseline comparison, model governance, operational prioritisation and evidence controls.

The project intentionally avoids claims that the public data cannot support. A positive night-flow anomaly is treated as an investigation signal rather than a confirmed leak. APR payment analysis is treated as regulatory decision support rather than causal evidence that an intervention would recover the observed payment exposure. Watsit signals are operational context rather than a formal drought classification.

For recruitment use, the strongest current executed evidence is the official APR analysis, APR-to-EDM source reconciliation and Watsit operational context layer. Night-flow ML performance should only be quoted after the network-enabled workflow has run successfully on the public ArcGIS record-level data and the evidence register marks those outputs as executed real-data evidence.
